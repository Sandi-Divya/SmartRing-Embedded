# SR08 / Companion App

A clean React Native mobile companion app built with Expo and `react-native-ble-plx` to interface with the SR08 hardware ring over Bluetooth Low Energy (BLE).

## Features
* **BLE Scanner & Connector:** Automatically discovers and connects to `DLG-PRPH` target devices.
* **Ring Controls:** Send single digits or alphanumeric characters over custom BLE characteristics.
* **Live Telemetry & Battery Monitoring:** Subscribes to telemetry notifications and tracks power levels.
* **Calm Aesthetic:** Designed with a soothing, dark obsidian and warm sand palette.

## Tech Stack
* **Framework:** React Native / Expo
* **BLE Library:** `react-native-ble-plx`
* **Language:** TypeScript
